# Backend

API REST do Sistema de Gerenciamento de Chamados, desenvolvida com Laravel.

Consulte o [README da raiz](../README.md) para a configuração completa do ambiente, banco de dados, autenticação SPA e credenciais de demonstração.

Comandos principais:

```bash
composer install
php artisan migrate --seed
php artisan serve --host=localhost --port=8000
php artisan test
./vendor/bin/pint --test
```
