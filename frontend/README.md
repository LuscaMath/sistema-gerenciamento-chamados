# Frontend

SPA do Sistema de Gerenciamento de Chamados, desenvolvida com Vue 3 e TypeScript.

Consulte o [README da raiz](../README.md) para a configuração completa do ambiente, incluindo a integração com Laravel Sanctum.

Configure `VITE_BACKEND_URL` em `.env` com o endereço da API e execute:

```bash
npm install
npm run dev
npm run lint
npm run type-check
npx vitest run
npm run build
```
