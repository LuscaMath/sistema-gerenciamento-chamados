# Sistema de Gerenciamento de Chamados

Projeto desenvolvido para a disciplina Optativa II.

O sistema tem como objetivo permitir o registro, acompanhamento e atendimento de chamados técnicos por meio de uma arquitetura separada entre frontend e backend.

## Tecnologias previstas

### Backend
- Laravel
- Laravel Sanctum
- MySQL
- Pest

### Frontend
- Vue 3
- TypeScript
- Axios
- Pinia
- Tailwind CSS
- Vitest

## Estrutura

- `backend/` - API REST desenvolvida em Laravel
- `frontend/` - aplicação cliente desenvolvida em Vue
- `docs/` - documentação do projeto
